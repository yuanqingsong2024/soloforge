# SoloForge 发布就绪总方案

> 权威入口：所有发布硬化工作以本文件及其关联文档为准。
> 当前结论：**No-Go**。文档完成不等于软件已发布。

## 1. 目标

本方案只解决一件事：把当前 SoloForge 工作区收敛为可复现、可验证、可回滚的内部稳定版。停止新增产品功能，优先修复真实执行、数据完整性、安全和发布工程问题。

发布目标不是公网 SaaS，而是：

- 本地优先
- 默认关闭遥测
- 默认不自动更新
- 高危动作人工审批
- 审计可验证
- 凭证不明文落盘
- 内部可安装、升级和回滚

## 2. 当前判定

| 项目 | 当前证据 | 判定 |
|---|---|---|
| TypeScript | `npx tsc --noEmit` 通过 | 通过 |
| 单元测试 | 100/100 通过 | 通过 |
| Renderer 测试 | 21/21 通过 | 通过 |
| 集成测试 | 62 通过、2 失败 | 阻断 |
| 生产构建 | Vite 成功，electron-builder 失败 | 阻断 |
| 工作树 | 大量修改和未跟踪文件 | 阻断 |
| 出站消息 | 存在未真实发送却可标记 `SENT` 风险 | 阻断 |
| 配置应用 | 存在占位函数返回成功风险 | 阻断 |
| 审计 | 写入失败不一定阻断业务；哈希链并发待修复 | 阻断 |
| 发布制品 | 未形成可追踪的三平台制品和校验记录 | 阻断 |

## 3. 发布门禁

### P0：必须关闭

1. 出站消息没有真实成功结果时不得进入 `SENT`。
2. Claude Code/OpenClaw 配置未实现时不得返回成功；真实应用必须回读校验。
3. 所有高危审批动作都有真实 handler，未实现动作明确失败。
4. 高危动作审计失败时不得继续执行，或进入明确的待审计失败状态。
5. 修复两个集成测试失败，并确认不是数据库隔离掩盖产品缺陷。
6. 修复 electron-builder 重复构建失败，在干净环境生成安装包。
7. packaged app 禁止 `SOLOFORGE_E2E=1` 绕过认证。
8. 数据库迁移可从零重放，并能从上一内部版本升级。
9. 发布提交可追踪，工作树干净，临时目录不进入制品。

### P1：稳定版前必须完成或有书面豁免

- 生产 CORS 不再默认反射任意 Origin。
- 审计哈希链具备确定追加顺序和并发保护。
- safeStorage 外层文件具备原子写入、权限和结构校验。
- 备份/导出递归验证敏感字段不泄露。
- 生产错误响应脱敏。
- 三平台制品具备 SHA-256；可行时使用代码签名。
- 完整 E2E 纳入统一门禁，避免本地白名单和 CI 全量不一致。
- README、DEVELOPMENT、路线图和版本号状态一致。

### P2：可在稳定版后处理

- 收紧生产 CSP 到实际端口。
- renderer 不再持有长期 API token，改为主进程代理。
- 标准化 `timingSafeEqual`。
- 工具链弃用警告清理。
- 性能、可访问性和真实远程环境扩展测试。

## 4. 分阶段实施

### 阶段 A：冻结与基线

- 确定发布分支和版本号。
- 清理未跟踪临时文件，审查全部源码和迁移。
- 形成唯一发布提交。
- 固定 Node、npm、Electron、Prisma 和依赖锁文件。

### 阶段 B：正确性硬化

- 修复出站、配置、审批执行和集成测试。
- 为失败、重试、幂等、回滚补充测试。
- 任何未实现能力改为明确失败或禁用。

### 阶段 C：安全与数据硬化

- 审计 fail-closed 和哈希链串行化。
- 生产认证、CORS、错误脱敏和 E2E 旁路隔离。
- 凭证、备份、导出和 SQLite 迁移验证。

### 阶段 D：发布工程

- 三平台原生构建。
- 生成制品 hash/签名并归档。
- 安装、首次启动、升级、迁移、恢复和回滚冒烟。
- 内部候选版观察后作 Go/No-Go 决策。

## 5. Go/No-Go 规则

只有同时满足以下条件才能 Go：

- P0 问题全部关闭并有证据。
- 集成、E2E 和核心手工验收无阻断失败。
- 生产构建和安装启动成功。
- 迁移、备份、恢复和回滚通过。
- 高危动作均能证明“未批准不执行、失败不伪成功、执行有审计”。
- 制品 hash/签名、版本、提交和环境信息已归档。
- 发布负责人、技术负责人和安全负责人完成签字。

任何一个条件不满足，都必须 No-Go；不能用“内部使用”替代核心安全和数据完整性门禁。

## 6. 证据要求

每项门禁必须保存：

- 命令和退出码
- 测试报告
- 构建日志
- 制品文件名和 hash
- 安装/升级截图或操作记录
- 数据库迁移清单
- 已知限制和回滚步骤

“代码看起来正确”不是发布证据。
